# 🚀 Numeo is hiring — Mid-Level & Senior AI Engineers

Yo folks! We're expanding 🙂

We're looking for engineers who've shipped LLM-powered systems in production, have opinions on architecture, and want to grow fast.

---

## 🛠 What you'll do

- Design and ship LLM-powered agents end-to-end — from prompt engineering to production observability
- Make architecture decisions for agent workflows (LangGraph, agent loops, tool orchestration, RAG, voice)
- Build systems that make AI agents trustworthy in prod: evals, regression tests, hallucination guards, feature flags, gradual rollouts
- Work across the stack — backend in Node.js / Python, occasional React (MUI / Tailwind)
- Translate customer pain into AI capability — not build agents for the sake of it

---

## ✅ Requirements

- **Mid:** 3+ years in software engineering, hands-on shipping LLM-powered features
- **Senior:** 4+ years, at least 1 year shipping LLM-powered systems in production
- Strong in Python AND TypeScript / Node.js
- Hands-on with agent frameworks: LangGraph, LangChain, Haystack, Semantic Kernel, PydanticAI, or equivalent
- **AI-native:** comfortable using AI coding tools (Claude Code, Cursor, Codex, etc.) in parallel to ship several things at once. We expect you to multi-thread your own work
- System-thinking — you can answer *"what breaks first at 1000x scale?"* with specifics
- Proactive, full ownership mindset. You ship, you measure, you fix

### Hands-on experience with at least 2 of:

- **Vector or Graph DBs** — Pinecone, Weaviate, Qdrant, Milvus, Vespa, FAISS, Neo4j, TigerGraph, ArangoDB
- **Voice AI stacks** — LiveKit, Pipecat, Daily.co, Agora; Deepgram, ElevenLabs, Whisper, Rime
- **LLM observability** — Langfuse, LangSmith, Weights & Biases, OpenTelemetry
- **Eval frameworks** for non-deterministic systems
